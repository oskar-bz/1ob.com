### What a mel band is

Margin notes sit beside the line they annotate.<Sidenote>The mel scale compresses high frequencies roughly logarithmically, so the bands widen as they go up.</Sidenote> On a phone the number becomes a button that unfolds the note in place.

$$
m = 2595 \cdot \log_{10}\!\left(1 + \frac{f}{700}\right) \tag{1}
$$

### Choosing coefficients

```python
# centre frequencies, evenly spaced on the mel scale
def mel(f):  return 2595 * np.log10(1 + f / 700)
def hz(m):   return 700 * (10 ** (m / 2595) - 1)
centres = hz(np.linspace(mel(80), mel(7600), n_bands))
```
